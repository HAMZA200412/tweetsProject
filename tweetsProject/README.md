# Twitter Sentiment Analysis Web App 🐦💬

This Flask app scrapes tweets based on a topic, performs sentiment analysis using Hugging Face Transformers, and displays the results in a styled web interface.

## 🔧 Tech Stack
- Python 🐍
- Flask 🌐
- Selenium 🧪
- Hugging Face Transformers 🤗
- Pandas 📊
- HTML/CSS
